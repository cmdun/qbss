Getting started

Set up the question database

QBSS keeps the question collection on your computer. On first launch, select the extracted backup folder and QBSS will build and connect the local database for you.

1. Get a QBReader backup

Open the QBReader database backups page and download the most recent complete backup folder. The QBReader page links to its public backup archive. Keep all files together when extracting it.

QBSS is an independent project. The question collection is separate from the QBReader application source.

2. Import the backup

In the installed desktop app, choose Choose backup folder on the first launch prompt, or open Settings → Question database setup and choose it there. Select the folder containing prelude.json and the sets, packets, tossups, and bonuses files. QBSS checks the backup and builds the SQLite search index locally.

Keep all extracted files together. Importing can take a few minutes and temporarily needs room for both the old and new database. No Python installation is needed in the desktop app.

3. Restart and study

When the import finishes, restart QBSS to use the new database. Your stars, saved packets, and practice history stay in the separate personal.sqlite file.

The included command-line importer is also available for advanced setups and requires Python 3.

Keep your personal data private

personal.sqlite contains your stars, saved packets, and local study history. Don’t send it when sharing the public question database. Keep a backup of it if you want to preserve that information.
